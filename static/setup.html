LAPTOP + PHONE

A private connection.

Trust HTTPS before using the camera

  1. On the laptop, find its Wi-Fi IPv4 address with ipconfig.
  2. Run .\setup-https.ps1 -Ip YOUR_WIFI_IP from the I-SKAN folder.
  3. Install certs/root-ca.cer in the laptop’s Current User → Trusted Root Certification Authorities store. Install only the root certificate; keep private keys on the laptop.
  4. Transfer root-ca.cer to Android, for example by USB. In Android settings, find Install a certificate → CA certificate. Menu names vary by manufacturer. Installing a CA lets the phone trust certificates issued by this laptop; remove it when no longer using I-SKAN.
  5. Run .\start.ps1. Open the QR URL in Chrome on Android. Confirm there is no certificate warning. A bypassed warning does not guarantee a secure camera context.
  6. Enter the pairing code from the laptop, start a scan, and allow Camera. Verify the rear camera and inspect a test capture.

If it does not connect

Use the same private Wi-Fi. Keep the laptop awake and connected. Check Windows Firewall’s private-network rule for TCP 8443. Avoid guest Wi-Fi with client isolation. Do not forward this port on your router. If the IP changes, regenerate the server certificate with the new address; the existing root is reused.

Photo upload fallback

Choose Upload photos to take or select a photo. For a device that cannot trust HTTPS, .\start.ps1 -HttpLan explicitly enables HTTP photo upload on a private network. This connection is unencrypted, and the live phone camera is unavailable. Laptop-only mode is .\start.ps1 -Local.

Printing

A phone Print request marks the approved PDF ready in the laptop interface. On the laptop, open print preview and use the PDF viewer’s Print button or Ctrl+P. Printer options and actual printing depend on the viewer and printer; I-SKAN does not confirm physical printing.
